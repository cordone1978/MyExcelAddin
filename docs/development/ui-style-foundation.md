# UI 独立风格定义

最后更新：2026-03-30

## 1. 目标

本文件用于确定本项目后续统一采用的独立 UI 风格，作为页面改版、组件重构、样式评审和新页面开发的唯一视觉基线。

本风格不是继续沿用传统 Office 蓝色表单风格，也不是简单复制 `taskpane` 现状，而是在现有较优实现基础上收敛出一套稳定、可复用、适合本项目业务密度的界面语言。

## 2. 风格名称

风格名称：`Clear Industrial Blue`

中文工作名：`清晰工业蓝`

## 3. 风格定位

关键词：
- 清晰
- 稳定
- 专业
- 轻量层次
- 信息优先

不追求：
- 炫技感过强的互联网运营风
- 过深阴影和过重拟物
- 过于传统的 Windows 表单拼贴感
- 大量高饱和纯蓝块面

## 4. 使用场景

适用：
- Excel Add-in 任务窗格
- 配置与选择类对话页
- 信息参考页
- 图谱编辑器侧栏和工具区

特例：
- `quote-preview` 属于文档预览面，不强制完全一致，但应共享字体、状态色、浮层、菜单和基础 token。

## 5. 视觉原则

### 5.1 页面气质

- 页面背景保持浅灰蓝基底，避免纯白页面直接铺满。
- 卡片作为主要信息承载面，使用轻边框、轻阴影，不依赖重色块分区。
- 主色只用于操作、选中、高亮和关键状态，不用于大面积背景灌色。

### 5.2 信息层级

- 第一层：页面标题、主操作、当前关键状态。
- 第二层：分组标题、卡片标题、表格头部。
- 第三层：辅助说明、元信息、弱提示。

层级应该依靠字号、字重、留白和边框建立，不依靠多种颜色堆叠。

### 5.3 控件风格

- 控件整体采用中大圆角，避免 4px 小圆角的旧式表单感。
- 输入控件和按钮高度统一，优先保证点击和扫描效率。
- hover、focus、selected 必须有明确反馈，但动画幅度要小。

## 6. 品牌与语义颜色

### 6.1 品牌主色

- 品牌主色：`#0284c7`
- 主色渐变终点：`#0ea5e9`
- 主色深色态：`#0369a1`
- 主色浅底：`#e0f2fe`

说明：
- 所有交互型页面统一使用该主色，不再新增第二套主蓝。
- 原有 `#0078d4` 视为旧体系遗留色，后续逐步淘汰。

### 6.2 文档强调色

- 文档强调色：`#16a6dc`

说明：
- 仅用于报价预览、打印分组、文档结构强调。
- 不用于交互按钮、选中态、焦点态。

### 6.3 中性色

- 正文文字：`#1f2937`
- 次级文字：`#475569`
- 辅助文字：`#64748b`
- 页面背景：`#f8fafc`
- 次级背景：`#f1f5f9`
- 卡片背景：`rgba(255, 255, 255, 0.92)`
- 边框主色：`#cbd5e1`
- 边框弱色：`#dbe3ee`

### 6.4 状态色

## 7. 形状与空间

### 7.1 圆角体系

仅保留以下 4 档：
- `4px`：表格内小标签、极小型控件
- `8px`：次级容器、小型面板
- `12px`：输入框、按钮、常规卡片
- `16px`：主卡片、主面板、大容器

额外约束：
- `999px` 仅用于胶囊标签、状态 pill、圆形按钮。
- 禁止新增 `6px`、`10px`、`14px`、`18px` 作为常规圆角。

### 7.2 间距体系

仅保留以下主档：
- `8px`
- `12px`
- `16px`
- `24px`

建议：
- 组件内 gap 优先用 `8px` 或 `12px`
- 卡片内 padding 优先用 `12px` 或 `16px`
- 模块级区块间距优先用 `16px` 或 `24px`

### 7.3 阴影体系

- `shadow-sm`: 轻浮层、菜单、弱卡片
- `shadow-md`: 常规卡片、可点击容器
- `shadow-lg`: 模态框、重要浮层

原则：
- 阴影用于建立层次，不用于制造“厚重感”。
- 同一页面不应混用多种随机阴影参数。

## 8. 排版

### 8.1 字体

统一字体栈：

`"Segoe UI", "Microsoft YaHei UI", Tahoma, Arial, sans-serif`

说明：
- 中文界面必须保留 `Microsoft YaHei UI`。
- 禁止不同模块各自删减字体栈顺序。

### 8.2 字号

推荐字号：
- 页面主标题：`24px` 到 `26px`
- 区块标题：`16px` 到 `18px`
- 控件与正文：`13px`
- 辅助信息：`12px`
- 微型说明：`11px`

### 8.3 行高

仅保留以下 3 档：
- `1.2`：大标题、数字型短文本
- `1.45`：表格单元、紧凑正文
- `1.5`：正文、说明、反馈信息

`1.55` 和 `1.6` 只在较长说明文本中按需使用，不作为默认值。

## 9. 核心组件样式基线

### 9.1 按钮

主按钮：
- 高度：`40px`
- padding：`12px 16px`
- border-radius：`12px`
- 背景：主色渐变
- 字重：`600`

次按钮：
- 高度：`40px`
- padding：`12px 16px`
- border-radius：`12px`
- 背景：白色
- 边框：中性弱边框

交互：
- hover 可上浮 `1px`
- active 恢复原位
- focus 必须提供 3px 左右外发光或描边

### 9.2 输入框

- 高度：`40px`
- padding：`12px 13px`
- border-radius：`12px`
- 边框：`1px solid` 中性边框
- 背景：接近白色的浅底

交互：
- focus 使用品牌主色
- 禁止保留旧式 `1px` 细弱焦点阴影

### 9.3 列表项

- 默认背景尽量轻
- hover 使用浅蓝底
- selected 使用主色背景或主色浅底 + 强边框

说明：
- 信息参考页和 dialog 列表框必须统一选中策略，不再混用旧蓝。

### 9.4 卡片

- 常规卡片圆角：`12px` 或 `16px`
- 内边距：`12px` 或 `16px`
- 边框和阴影二选一可同时保留，但都应偏轻

### 9.5 表格

- 表头、汇总行、状态列可以使用轻背景区分
- 禁止使用大面积高饱和纯色填充普通数据区
- 表格内容优先保证对齐、扫描效率和密度控制

## 10. 动效原则

- 仅保留必要动效：hover、selected、modal、drawer
- 时长建议：`120ms` 到 `180ms`
- easing 以 `ease` 或轻缓曲线为主
- 禁止大范围弹跳、旋转、夸张位移

## 11. 禁止项

- 禁止新增 `#0078d4`、`#d13438`、`#333`、`#222`、`#666`
- 禁止直接复制旧 dialog 页面的 `.btn`、`.input` 到新模块
- 禁止在新页面继续引入 6 种以上圆角档位
- 禁止在同一页面同时出现“纯旧式蓝表单”和“玻璃感现代卡片”

## 12. 风格落地策略

后续实现统一按以下顺序进行：

1. 先建立 design tokens
2. 再抽取共享按钮、输入框、卡片、列表、标签样式
3. 然后迁移 `info-reference`、`queryprice`
4. 最后清理 `dialog`、`devmodify`、`craftmodify`

## 13. 验收标准

满足以下条件，才可视为符合本风格：

- 页面只使用统一 token，不直接硬编码旧色
- 按钮和输入框外观、尺寸、交互一致
- 圆角档位不超出规范
- 文本颜色只使用统一语义色
- 页面层级主要依赖留白、边框、字号，而不是杂乱色块
